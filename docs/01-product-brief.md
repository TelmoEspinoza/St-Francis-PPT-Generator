**Last updated:** 2026-07-27

## 1. 📌 Problem

Priests sacristans and Cruch Helpers need to create Psalter Power Point Documents twice a day. The process is repetitive, time consuming and pront to error. PTT's ussually containg errors, diferent formats and the Digital repository is big and messy.  

## 2. Solution

St Francis PPT-Generator is a web application that takes structured or unstructured Psalter information as input (hymns, antyphons, psalms, paryers) and automatically produces a formatted `.pptx` document applying a consistent template, layout, and styling with minimal manual work.

## 3. Target Users

- Primary: priest and sacrystans who regularly build presentations (documentss) and want a fast first draft.
- Church Helpers: non-technical users who need a simple interface, no PowerPoint expertise required.

## 4. Goals (MVP)

1. Create, update and delete Items (hymns, antyphons, psalms, paryers) input text int a common database.
2. Generate a clean, configurable template multi-slide `.pptx` file. (Foreword, title header, content, Afterword).
3. Let the user download or save the generated document.

## 5. Non-Goals (for now)

- Real-time collaborative editing.
- Full design customization (advanced themes, animations).
- Multi-format export beyond `.pptx` (e.g., Keynote, Google Slides) — future consideration.

## 6. Success Metrics

| Metric | Target |
| --- | --- |
| Time to generate a 30+ slide document | < 10 minutes |
| Manual edits needed after generation | < 5% of slides |
| First-run success rate (no errors) | > 95% |

## 7. Constraints & Assumptions

- Small project, single developer or small team.
- Input format(s) to be finalized in Functional Requirements.
- No enterprise compliance requirements at MVP(Minimun Viable Produc) stage.
